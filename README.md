# How to Run the Program

1. Have Python and Pip installed, Wifi is also necessary for first run  
2. If on Windows, run (e.g. double-click) the `run.bat` file inside the `App folder`
3. If on Mac or Linux, run the `run.sh` file  
4. If on Linux, run `chmod +x run.sh` inside the folder of the script and then run it like `./run.sh`

# To Share it over a network (on Windows)

1. Run `firewall_bypass.bat` that allows traffic on the 8081 port
2. Run the `getip.bat` script to get you ip on the network
3. After that other people can connect on the network by accessing the website `<yourip>:8081`
